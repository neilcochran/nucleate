    Type Alias Result<T, E>

    Result: SuccessResult<T, E> | FailureResult<T, E>

    Discriminated-union result type carrying either a successful payload or a failure error.

    A Result<T, E> is either:

    • SuccessResult - carries a data: T payload, with success === true
    • FailureResult - carries an error: E payload, with success === false

    Designed so that if (result.success) narrows the type to the success branch (and vice versa), preserving the discriminated-union ergonomics. Each branch additionally carries fluent methods (map, chain, unwrap, etc.) for transforming and unwrapping results.

    Construct via success / failure.

    Type Parameters

    • T

      Type of the data carried on success

    • E = string

      Type of the error carried on failure (defaults to string)
