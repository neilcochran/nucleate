    Tagged-union errors raised by the Okazaki-fragment parsers (parsePrimerOnlyFragment, parseSynthesizedFragment, parsePrimerRemovedFragment, and parseLigatedFragment).

    • okazaki/empty-id: the supplied identifier was an empty string.
    • okazaki/invalid-position: the start position was not a non-negative integer.
    • okazaki/invalid-range: endPosition was not strictly greater than startPosition.
    • okazaki/primer-position-mismatch: the primer's position did not equal the fragment's startPosition.
    • okazaki/sequence-length-mismatch: an optional sequence was supplied whose length did not equal endPosition - startPosition.
