    IUPAC nucleotide pattern symbols mapped to the concrete bases each one matches.

    Declared as const so callers receive deeply-readonly literal types: the keys are the exact IUPAC symbols and each value is a readonly tuple of base letters. Order within each tuple is the conventional ordering used in IUPAC documentation.
