    Function findPromoters

    • findPromoters(dna: DNA, options?: PromoterSearchOptions): Promoter[]

      Finds potential promoters in a DNA sequence by locating IUPAC-pattern matches for the configured element set, clustering them around a predicted TSS, and emitting one Promoter per cluster that meets the minimum-elements and minimum-strength thresholds.

      Returned promoters are sorted by Promoter.getStrengthScore descending so the caller can use the first entry as the most likely real promoter.

      Parameters

      • dna: DNA

        The DNA sequence to scan

      • options: PromoterSearchOptions = {}

        Optional search-tuning parameters

      Returns Promoter[]

      Array of candidate Promoter objects, strongest first

      Example

      const dna = parseDNA('GGCCAATCTATAATGCATGCCC').unwrap();
      const promoters = findPromoters(dna);
      console.log(`Found ${promoters.length} potential promoters`);
