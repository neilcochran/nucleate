    • at<T>(target: readonly T[], key: number): T

      Indexed access helper for sites where the index is proven in-bounds by an upstream invariant (a loop bound, a length check, a structural guarantee). With noUncheckedIndexedAccess enabled, arr[i] widens to T | undefined; this helper narrows it back to T and throws a precise RangeError if the contract is violated - which can only happen on a programmer error, not a runtime input failure.

      Use this where the surrounding code already establishes the index is valid. Where the index might legitimately miss (e.g. a hash-table lookup that may not find a key), use the plain ?? fallback or explicit undefined check instead - those cases are real branching logic, not invariant assertions.

      Two overloads cover the common cases: array-style numeric index, and record-style string key.
