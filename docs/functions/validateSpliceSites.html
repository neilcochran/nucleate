      Validates that introns follow the canonical DNA splice-site consensus (GT...AG).

      Operates on DNA-side coordinates (T, not U). The matching transcript-coordinate validator used internally by spliceRNA enforces the equivalent GU...AG rule on the RNA strand.

      The result carries the first failing splice-site rule (donor, acceptor, or length), so callers can compose this validator with the other tagged-union failure paths in the splicing pipeline.
