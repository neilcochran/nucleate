      Splices a pre-mRNA according to a specific splice variant, returning the spliced RNA (introns removed, variant-included exons concatenated, U bases).

      This performs only the splicing step. The result is a spliced transcript, not a mature mRNA - no 5'-cap is added, no polyadenylation site is located, no poly-A tail is appended, and no coding-sequence boundaries are identified. Callers needing a fully-processed mature mRNA should use processSpliceVariant instead.

      Parameters

        The pre-mRNA whose source gene the variant references

      • variant: SpliceVariant
