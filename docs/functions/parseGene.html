      Parses an untrusted DNA-sequence string and exon list into a Gene.

      The pipeline is, in order:

      1. Parse the sequence string into a DNA via parseDNA (returns invalid-sequence on failure)
      2. Run validateExons against the parsed sequence length (returns the structured exon-rule failure on failure)
      3. If a splicing profile is supplied, validate it against the exon count (returns invalid-splicing-profile on failure)
      4. Brand the exons as GeneCoord regions, derive intron regions, and construct the Gene

      Parameters

      • sequence: string

        Candidate DNA sequence (case-insensitive)

      • exons: readonly GenomicRegion<number>[]

        Exon regions in gene-relative coordinates

      • Optionalname: string

        Optional gene name

      • OptionalsplicingProfile: AlternativeSplicingProfile

        Optional alternative-splicing profile

      Returns Result<Gene, GeneError>

      Result whose success branch carries a Gene and whose failure branch carries a GeneError

      Example

      const result = parseGene('ATGCCCGGGAAATTTAAA', [
        { start: 0, end: 6, name: 'exon1' },
        { start: 12, end: 18, name: 'exon2' },
      ], 'BRCA1');
      if (result.success) {
        console.log(result.data.exons.length); // 2
      }
