    Interface Promoter

    A gene promoter: the cluster of regulatory elements that initiates transcription, together with the transcription start site (TSS) they orient against.

    Public construction goes through parsePromoter; the constructor is module-private and is not part of the package's public surface.

    getStrengthScore

    • getStrengthScore(): number

      Computes a coarse strength score for the promoter by summing each element's scoreWeight and adding a synergy bonus when more than one element is present.

      This is a simplified model: real promoter strength depends on sequence context, chromatin state, and many other factors. It is useful for ranking candidate promoters against each other in findPromoters, not as an absolute biological measurement.

      Returns number

      The promoter strength score (higher = stronger)
