    Interface AminoAcid

    A proteinogenic amino acid as encoded by a specific RNA codon.

    Composition over inheritance: an AminoAcid has an RNA codon and has a AminoAcidData payload; biochemical properties (name, singleLetterCode, molecularWeight, etc.) live on data.

    Public construction goes through parseAminoAcid (for reconstruction from raw codon strings) or through the translate pipeline (for the mRNA -> polypeptide flow). The constructor is module-private and is not part of the package's public surface.

    getAllAlternateCodons

    • getAllAlternateCodons(): Codon[]

      Returns every codon that codes for this amino acid (including the one carried by this instance), as fresh Codon instances. Alternate codons are the silent third-base substitutions of degenerate codes.

      Returns Codon[]

      Array of Codon values, in canonical order matching data.codons

      Example

      const alanine = parseAminoAcid('GCA').unwrap();
      alanine.getAllAlternateCodons().map(c => c.sequence); // ['GCA', 'GCC', 'GCG', 'GCU']

    • isAlternateOf(other: AminoAcid): boolean

      Reports whether another amino acid is the same proteinogenic type as this one but is encoded by a different codon. Returns false for identical-codon comparisons (including with this).

      Parameters

      • other: AminoAcid

        The amino acid to compare against

      Returns boolean

      true if the two amino acids share a AminoAcidData but have different codons

      Example

      const a1 = parseAminoAcid('GCA').unwrap();
      const a2 = parseAminoAcid('GCC').unwrap();
      a1.isAlternateOf(a2); // true (both Alanine, different codons)
      a1.isAlternateOf(a1); // false (same codon)
