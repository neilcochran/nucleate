    Optional ReadonlyvalidateCodons

    validateCodons?: boolean

    Whether a coding sequence is required. The pipeline always searches for a CDS (the first start codon followed by an in-frame stop). When true, a spliced sequence with no such CDS is rejected. When false, it is tolerated: the resulting mRNA carries no coding boundaries (codingStart / codingEnd / codingSequence are undefined). Disable for mutation modeling that intentionally disrupts the coding sequence.
