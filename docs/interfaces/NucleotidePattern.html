    Interface NucleotidePattern

    A nucleotide pattern compiled from an IUPAC notation string (e.g. 'TATAWAR', 'GAATTC', 'CANNTG'). Each IUPAC symbol expands into a case-insensitive regex character class and the non-alpha characters of the source string (regex quantifiers, anchors, brackets, escapes, grouping) are preserved as-is, so quantified expressions like 'GU{3,}' and grouped expressions like '(GT|AG)' are supported.

    Pattern methods accept either a validated DNA / RNA sequence or a raw string; the alphabet-agnostic IUPAC regex compilation already case-folds, so a string input is treated as a sequence of nucleotide characters without re-validation. Use the typed inputs when the caller already holds a parsed sequence; the string overload is a convenience for one-off matches. Public callers construct instances via parseNucleotidePattern; the constructor is module-private and is not part of the package's public surface.

    complement

    • complement(): NucleotidePattern

      Returns a new NucleotidePattern representing the IUPAC complement of this pattern. Each IUPAC symbol is replaced by its complement (A complements to T, C to G, R to Y, K to M, B to V, D to H; the palindromic codes S, W, and N complement to themselves; U complements to A). Regex meta-characters in the pattern string are preserved verbatim.

      Returns NucleotidePattern

      A new NucleotidePattern carrying the complement

      Example

      parseNucleotidePattern('ATCG').unwrap().complement().pattern; // 'TAGC'
      parseNucleotidePattern('RY').unwrap().complement().pattern;   // 'YR'

    • findAll(sequence: string | DNA | RNA): readonly NucleotideMatch[]

      Returns every occurrence of this pattern in the given nucleic-acid sequence. Overlapping matches are not reported (this follows JavaScript's native matchAll semantics).

      Parameters

        The DNA or RNA sequence to search

      Returns readonly NucleotideMatch[]

      Example

      const pattern = parseNucleotidePattern('RY').unwrap();
      pattern.findAll(parseDNA('ATGAGCGATC').unwrap());
      // [{ start: 0, end: 2, matched: 'AT' }, { start: 4, end: 6, matched: 'GC' }, { start: 6, end: 8, matched: 'AT' }]

    matchesEitherStrand

    • matchesEitherStrand(sequence: DNA): boolean

      Reports whether this pattern matches either the forward strand or the reverse-complement strand of the given DNA sequence. Restricted to DNA because the "either strand" concept is specific to double-stranded DNA; RNA is single-stranded and has no opposite strand to match against.

      Parameters

      • sequence: DNA

        The DNA sequence to test against both strands

      Returns boolean

      true iff the pattern matches on the forward or reverse-complement strand

      Example

      const ecoRI = parseNucleotidePattern('GAATTC').unwrap();
      ecoRI.matchesEitherStrand(parseDNA('CTTAAG').unwrap()); // true (reverse complement of GAATTC)
