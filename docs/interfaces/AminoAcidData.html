    Interface AminoAcidData

    Immutable biochemical data for a single amino-acid type.

    One AminoAcidData entry exists per proteinogenic amino acid in the canonical AMINO_ACIDS list. Codon-to-amino-acid and single-letter-to-codon lookup maps are derived from that list at module load, so this interface is the single source of truth for the codon table.
