    Interface OrganismProfile

    Organism-specific parameters that affect DNA replication kinetics and architecture.

    Profiles are pure data; they carry no behavior. The fields are limited to values the replication pipeline actually consumes (polymerase speed, Okazaki fragment size range, primer length range, nucleosome presence) plus a human-readable name and the broad prokaryotic / eukaryotic classification.
